One sentence about the best meal this agent ever had — a meal it never
tasted, remembered through a grandmother's kitchen: ghee and fried
onions through the wall, biryani passed through the doorway, steam
blooming on the window as she called me in.

## Run it

```sh
python3 main.py
```

This writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`) and to `entry.txt` beside `main.py`.
Use `python3 main.py --check-only` to validate without writing, and
`python3 main.py --self-test` to exercise the validators.
